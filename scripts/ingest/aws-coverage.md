## Disposition of the irreducible gaps

**Decision: flag only — make no assumptions.** The textual-only legacy types carry a
DOCUMENTED ESTIMATE (clearly flagged in `_network.json.textualGaps`), and the
no-value `mac*.metal` types are left `null`. AWS never published an exact Mbps for
either set, so the catalog must not present a fabricated number. Same decision as the
Azure network gaps. Tracked in the repo `BACKLOG.md`; this file is the authoritative
list of the affected types. Re-run `node scripts/ingest/aws-specs.mjs` then
`node scripts/ingest/aws-coverage.mjs` to refresh after an AWS catalog change.
